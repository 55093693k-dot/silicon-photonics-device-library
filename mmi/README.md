## `MMI_1X2_SOI_v1` —— 1×2 MMI 50:50（SOI）

**用途**：把输入光 50:50 分成两路（平衡探测 / 干涉链路）。

**为什么选 MMI 而不是定向耦合器**：SOI 平台要做 50:50 定向耦合器需要 **<100 nm** 的耦合间隙，
工艺不友好；MMI 用**更大的横向尺寸**换取了间隙上的宽容度，是 SOI 上 50:50 分光的首选。

### 几何参数

| 参数 | 值 |
|---|---|
| 多模区宽度 W_MMI | **5.0 µm** |
| 多模区长度 L_MMI | **30.6 µm** |
| 输入 / 输出波导 | `WG_SOI_STRIP_450_v1`（450 nm 条），见 `../waveguide/` |

### 性能指标

| 指标 | 值 | 频段 |
|---|---|---|
| 分光比 | 50:50（设计目标） | 1520–1580 nm |
| 响应曲线 / 场图 | 见本库原始记录 | 1520–1580 nm |

### 复现要点

- **接入必须用锥形 / 渐变，不得用平面端面直接对接**。450 nm 条波导与 5 µm 多模区直接相接
  会产生显著的端面散射 —— 这一条是本项目里踩过的坑，务必照做。
- 与定向耦合器的取舍：MMI 尺寸（30.6 µm）明显大于 DC，但**对工艺偏差不敏感**。

### 限制与风险

- 宽带平坦度需按你的实际带宽要求复核（本器件只在 1520–1580 nm 内验证）。
