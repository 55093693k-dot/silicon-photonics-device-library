# 波导库 —— 单模条波导截面

两个平台的**基准条波导**：所有下游器件的输入/输出都用它。数值来自本征模求解（FDE），
并用 3D 参考直波导做了传输级交叉核对。

## 1. `WG_SOI_STRIP_450_v1` —— SOI 单模条波导（450 / 500 nm）

### 几何参数

| 参数 | 值 | 备注 |
|---|---|---|
| 波导宽度 W | **450 nm**（推荐）/ **500 nm** | 两者均为**准单模**（TE0 主模，高阶模近截止） |
| 高度 H | 220 nm | SOI 标准顶层硅 |
| 包层 | SiO₂ / 空气（按工艺） | — |

### 性能指标

| 指标 | 值 | 频段 / 口径 |
|---|---|---|
| 单模条件 | 450 / 500 nm 准单模 | 1520–1580 nm |
| TE0 有效折射率 | **2.3537** | 1550 nm，3D，10 nm 网格 |
| TM0 有效折射率 | **1.7153** | 同上 |
| 参考直波导传输 | TE0 **99.7%** / TM0 **92.0%** | 1550 nm，3D 场积分，10 nm 网格 |

宽度扫描（400–600 nm）的完整 neff / ng 表见本库原始记录，不在本仓内。

### 复现要点

- **截面求解必须自己加网格覆写**。默认自动网格在本结构上实测偏低 0.02–0.10，
  必须加密到结果不再变化（本项目的收敛做法：20 / 10 / 5 nm 三级覆写）。
- **这两个 neff 值可直接当模式识别基准**：在端口模式列表里不按序号认模，
  而是按 neff 认模（TE0 ≈ 2.35、TM0 ≈ 1.72）。理由见根目录 README 的"数据可信度"一节。

### 限制与风险（含一处已知未决项）

- 500 nm 已接近单模边界，工艺偏差下可能激励高阶模。
- neff 依赖 220 nm 硅厚，实际工艺厚度偏差需重核。
- ⚠️ **已知未决（原文保留）**：同条件（450×220、n = 3.476 / 1.444、SiO₂ 包层、1550 nm）
  本地 FDE 在 **20 / 10 / 5 nm 网格覆写**下收敛到 **TE0 2.306 / TM0 1.7085**，
  比上表 3D 值低 **TE0 −0.048（约 2%）/ TM0 −0.007** ⇒ **仅 TE0 差异未定位，记为未决**。
  已排除的根因候选：不是频点取错（参考 CSV 的 1550 nm 行就是 2.3537）、不是网格不足
  （5 nm 与 10 nm 只差 0.002）。**本项目不改记录值、也不取平均。**
  影响评估：两者间隔约 0.6 ⇒ **模式识别不受影响**；450 nm 几何匹配不受影响。
  ⇒ 用于**模式识别**两个值都可靠；做**定量相位 / 色散设计**时优先用 FDE 收敛值并注明来源。

## 2. `WG_SIN_STRIP_1000_v1` —— SiN 单模条波导（1000 / 1200 nm）

### 几何参数

| 参数 | 值 | 备注 |
|---|---|---|
| 波导宽度 W | **1000 nm**（推荐）/ **1200 nm** | 两者均为**严格单模** |
| 其他已扫宽度 | 800 / 1500 nm | 1500 nm 可能多模 |

### 性能指标

| 指标 | 值 | 频段 / 口径 |
|---|---|---|
| 单模条件 | 1000 / 1200 nm 严格单模 | 1520–1580 nm |
| neff / ng | 完整表见本库原始记录（本仓未摘录） | FDE，2D 截面 |

本器件的验证等级是**模式求解级**（2D FDE），**未做 3D 全矢量重跑**。

### 复现要点

- 严格单模窗口比 SOI 宽得多（弱限制），但代价是**弯曲半径大**（见 `../bend/`）。
- SiN 的折射率差按 0.75% 计；实际工艺参数需重核。

### 限制与风险

- 宽 SiN 条与 SOI 的**模式尺寸差异大**，异质对接必须另做转换器；
  早期试过的"SiN 覆盖臂"路线已否决（FDE 转换 ≤ 11.2%，属弱杂交机制的上限）。
- 与 SOI 直接对接不可行。
