# 硅光无源器件素材库（SOI / SiN）

一组**可直接复用的硅光无源器件参数、真实仿真图与可跑脚本**，覆盖波导、定向耦合器、
MMI、延迟线、Euler 弯曲，以及一条完整的**偏振分束旋转器（PSR）链**。

所有数据来自同一个工程：为 **FMCW LiDAR 接收链路**做器件选型与验证时的仿真记录。
器件都是通用拓扑，参数、结论、以及**失败的结论**都原样放在这里。

> 作者：**Chan King Ho** ｜ 数据时间：2026-08 ~ 2026-09
> 工具：Ansys Lumerical 2025 R1（MODE / FDTD，本地）+ Tidy3D（云端 3D FDTD / EME）

---

## 1. 这个库解决什么问题

做硅光器件仿真时，最贵的不是算力，是**踩坑的时间**。这个库想省掉三类时间：

1. **不用从零扫参数**：波导宽度、耦合间隙、耦合长度这些已经扫过的量，直接拿结果。
2. **不用重新踩坑**：哪些方案在这个平台上根本走不通、为什么走不通，写在 `psr/rejected/` 里，
   带数据、带机制解释。
3. **不用猜数据可不可信**：每个器件都标了**验证等级**，标了哪些数能引用、哪些不能。

## 4. 三个使用层次

**① 只想查一个数**（选型、做预估）

直接看上面总表 → 进对应目录的 `README.md`，里面有几何参数表、性能指标表和限制说明。

**② 想复现或自己跑一遍**

每个器件目录下的 `sim/` 里有可运行的工程脚本，`data/` 里有验证数据 CSV。
脚本自带几何 / 材料 / 网格 / 源 / 端口定义，**不依赖仓库外的任何文件**。
本地部分（模式求解、结构图）免费；云端 3D 部分按 Tidy3D 计费，脚本会先打印估算成本再提交。

**③ 想看别人怎么失败**

`psr/rejected/` —— 四个被否决的偏振方案，每个都写了：试了什么、数据是多少、判据是什么、
为什么会失败、（如果有）机制上的解释。这一份大概比前两类更省时间。

## 5. 关于数据可信度：请务必读这一段

这个库**不是**一个"每个数都能直接用"的库。它的设计原则是**把不确定性标出来**，所以：

- 每条指标都带**证据说明**（哪个求解器、什么网格、什么口径）。
- 标 🔄 的器件**不要**拿去做下游设计的约束 —— 它们卡在哪一项、为什么卡，都写在器件 README 里。
- **二维（FDE / 超模）结果只是代理量，不是器件性能**。本库里最典型的一例：
  同一耦合结构，2D 超模给 99.99% 传输，3D 全波只有 83.1%；耦合长度 2D 给 15.8 µm，
  3D 反推 ≈130 µm。最终尺寸必须在 3D 里定。
- **绝对插损不是都能引用**。有一处例外已经写死在器件 README 里：`PSR_ROTATE_ADIABATIC_BLT_v1`
  的**器件级绝对插损不可引用**（原因：EME 端口功率逐列和恒 ≈1，基内没有辐射损耗通道；
  且已实测"加模式数也不暴露辐射损耗"）。这一条在对应 README 与数据 CSV 里都原文保留。
- 数值上的**已知未决项**（例如某个 neff 在两种方法间差 2%）：写在器件 README 的
  "限制与风险"里，**不做平均、不做掩盖**。

- 本库为**个人仿真研究记录**，供同行参考；**不构成任何流片、工艺或产品保证**。

## 7. 图件渠道说明（按"图是谁画的"分级）

**先说结论：本库 16 张 PNG，目前都还不带机器可读的渠道标签**（这是已知缺口，见本节末）。

本库图件按来源分两类：

| 类别 | 文件 | 数据来自 | 图是谁画的 |
|---|---|---|---|
| **真实求解器数据的成图** | `waveguide/*_xsec_FDE_mode.png`、`coupler/*_field.png`、`mmi/*_field.png`、`bend/*_field_topview.png`、`psr/split_TE_TM_DC/*_mode_maps.png`、`psr/rotate_adiabatic_BLT/data/PORT_MODE_FIELDS.png` | **求解器**（FDE 模式解 / FDTD、EME 场数据） | **matplotlib**（含离线出图脚本，如 `plot_mode_fields` 类脚本） |
| **从模型 / 几何参数重绘的结构图** | `delay_line/*_topview/xsec.png`、`psr/rejected/AMC_TAPER_v0_shape.png`、`psr/rotate_adiabatic_BLT/*_topview/xsec.png` | 几何参数或模型对象表 | **matplotlib**（`tools/make_structure_fig.py` 一类） |

**两类都属"外部绘图"渠道** —— 也就是说：**数据可以是求解器的，但图不是求解器导出的**，
引用时**不能**说成"求解器的结构视图 / 官方导出"。

**已知缺口（写在明处，不隐藏）**：
这 16 张图是在"渠道标签"约定落到生成器之前做出来的，所以**都不带** `External-Plot`
标签 chunk。目前的状态是：

- **新出的图已带标签**：`tools/make_structure_fig.py` 已改成"**写图即带标签**"
  （在图上画 footer ＋ 写进 PNG `tEXt`；`fig_channel` 不在时自动降级为普通保存，不会报错）；
- 用 `02_工具仓/fig_index/` 可以对任意图目录做审计并列出缺标签的图；
- 把历史图补成带标签版需要**重画**（原出图脚本不全在本库内），因此这一步留给你决定。

> 如果你要引用本库的图：请按上表**说明它属于哪一类**，不要当成求解器导出。
> 数值请引用器件 README（而不是从图上读）。
