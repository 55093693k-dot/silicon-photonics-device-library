# 被否决的方案 —— 四个偏振器件的否决记录

这一份大概是本仓**最省时间**的部分。四个方案都做到了"能跑出数"，都**没有**达到判据。
每个都写了：试了什么、数据是多少、判据是什么、为什么失败、有没有替代解释。

**它想省掉的是"再试一次同一个拓扑"的时间。**

|---|---|---|---|---|

## 1. 四种"杂交型"偏振旋转路线（整类否决）

被试过并否决的四条结构路线：

- SiN 覆盖臂（在硅波导上盖一段 SiN）
- SiN 叠层
- 双高度刻蚀
- 单侧 slab 锥形

**结果**：FDE 转换效率 **≤ 11.2%**。

**为什么整类都不可行**：这几条都属于"弱杂交"机制 —— 两种偏振之间的耦合强度本质上受
几何限制，能拿到的转换效率上限就在 10% 量级。**不是参数没调好，是机制给不出更高的值。**

**给同行的建议**：想要高转换效率，直接走**绝热模式演化**路线
（见 `../rotate_adiabatic_BLT/`），不要在弱杂交拓扑上花时间。

---

## 2. 直线非对称肋拍频旋转器

**结果**：3D 实测 TM0 → TE0 峰值 **20.3%**，判据是 ≥ 80%。

**为什么不行**：拍频（beat）机制要求两支持耦合模式的相位匹配足够好、耦合长度足够短，
而在 450 nm 条这一档几何上二者难以同时满足 ⇒ 峰值就停在 20% 量级。

## 3. `AMC_TAPER_v0` —— AMC 偏振旋转器（单肋宽度渐变 + FAQUAD）

### 器件定义

| 字段 | 内容 |
|---|---|
| 类型 | 偏振旋转器（TM0 → TE0，绝热模式耦合式） |
| 平台 | SOI 220 nm + **两次刻蚀**（部分刻蚀 70 nm，留 **150 nm slab**）+ SiO₂ 包层 |
| 材料 | Si n ≈ 3.476 ｜ SiO₂ n ≈ 1.444 |
| 工艺要求 | **双层刻蚀**（肋宽 0.45 → 0.80 µm 的宽度渐变）；器件长度 60 µm |
| 用途 | 把 TM0 旋转为 TE0，供 PSR 链第二步使用 |

| 图 | 说明 |
|---|---|
| `AMC_TAPER_v0_shape.png` | 几何形状示意（真实生成图） |

### 关键指标与判定

| 指标 | 值 | 判定 |
|---|---|---|
| TM0 → TE 旋转（linear / FAQUAD） | **86.5% / 89.7%** @1550 nm（峰值 88.6% / 91.9%） | ✅ 这一路是好的 |
| **TE0 直通（核心验收项）** | **27.3% / 18.2%** @1550 nm（波段最低 23.2% / 17.9%） | ❌ 判据 **≥ 80%** ⇒ **FAIL** |

### 否决理由

旋转通道本身可用（≈ 90%），但 **TE0 直通通道系统性失效**：
TE0 在 0.45 µm 窄端激发的宽度渐变上**散射很大**；
FAQUAD 形状优化只改善了旋转（+3 pt），却**进一步降低**了 TE 直通（−9 pt）。

**为什么"再调一调"不成立**：两个通道对几何的要求是**互相矛盾**的 ——
优化旋转的几何修改方向会恶化 TE 直通。这不是参数没调到位的局部最优问题。

### 待排除的替代解释（原记录保留）

1. 窄端高阶模近截止；
2. 该实现与论文里 all-rib PSR 的**接入 / 级联拓扑不同**
   （论文含 strip ↔ rib 转换与双端口接入）；
3. 两种求解器在**同截面谱上存在差异**（neff 约 0.5–0.8）未解决
   ⇒ **模式标签的可信度存疑**。

第 3 条尤其值得警惕：它意味着**"TE0 直通只有 18%"这个数本身也可能受模式标注影响**。
不过既然判据差了一倍以上，且机制上（窄端散射）有独立解释，本条仍按否决处理。

### 出处

- 文献路线：**Hung, Y. J. et al., *Opt. Lett.* **49**(7):1852–1855 (2024)**
  （all-rib STA 偏振分束旋转器）。
- **该文献的参数没有拿到**（付费墙、无预印本）⇒ 本器件按通用概念**自建假设参数**，
  在原始设计记录里明确标注为 ASSUMED。
  **⇒ 因此本条的否决结论应理解为"该假设参数下的实现不成立"，
  而不是"该文献方案不成立"。**

### 替代方案

需要偏振旋转请用 `../rotate_adiabatic_BLT/`（绝热双台阶锥旋转器）。

## 4. 官方 90° 弯曲一体化 PSR 复刻

**做法**：复刻一个公开的 90° 弯曲一体化 PSR 设计（官方示例），试图一次性完成
"分束 + 旋转"。

**结果**：**复刻成功，但平台适配失败** —— 在 C 波段 + 450 nm 条波导下，
**TM → TE 仅 1.9–14.5%**。

**机制解释**：**相位匹配成立，但耦合强度不足**。也就是说，
这不是"设计抄错了"，而是**该结构的设计波长 / 波导尺寸与本次目标平台不匹配** ——
同样的拓扑在本平台上给不出足够的耦合。

**成本记录**：本轮约 **0.975 FlexCredit**（云端）。

**给同行的建议**：拿公开设计做适配时，**先算耦合强度 / 耦合长度**，
再决定要不要花算力跑全器件 —— 这一条能直接省掉一轮云端开销。
