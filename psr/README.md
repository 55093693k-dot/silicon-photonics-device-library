# 偏振分束旋转器（PSR）链

光纤送进 PIC 的是**随机偏振**，而片上器件几乎都是偏振相关的。所以相干接收链路前面需要一条
**PSR 链**，把随机偏振规整成单路、单偏振的光。标准做法是三级：

```
随机偏振 ──▶ ① 分束（TE/TM 分离）──▶ ② 旋转（TM → TE）──▶ ③ 合路（两路 TE 合成一路）
                TE 直通                  TM0 → TE0               TE0 + TE0 → TE0
```

本目录收录的是**这条链的前两级**，加上**被否决的方案**。第三级（合路器）在本项目里没有开始做。

## 为什么这一块值得看

偏振旋转/分束是硅光里"看起来简单、做起来处处是坑"的一类器件。本目录里最值钱的部分不是
那两个 🔄 的成果，而是这两件事：

**① 一条被实测否证的直觉。**

"EME 的端口功率列和恒等于 1，说明加端口模式数就能把辐射损耗暴露出来。"
—— 本项目把端口模式数从 4 提到 6，转换率只变了 **−0.29%**（99.525% → 99.233%），
列和**仍然 ≈1**。结论：**在这个结构上，加模式数不暴露辐射损耗**，器件级绝对插损
只能走全器件 3D FDTD 或流片实测。

**② 两类"看起来是器件、其实是测量"的假象。**

- 端口模式数取 2 时，功率几乎全部留在那 2 个模式里（列和恰为 1、串扰量级极小）
  ⇒ 此时的绝对插损 / 回损是**测量口径**的产物，不是器件性能。
- 同一个器件换成 `passive` 约束、同样端口模式数，透射一度掉到 ≈0.14%（IL ≈28.5 dB），
  与 `unitary` 下的 92–97% 直接矛盾 ⇒ 说明**至少一个（很可能两个）由约束 / 端口模式截断主导**。
  这些数以前被当成器件指标用过，现在**全部标为不可引用**。

这两条都写进了对应器件 README 的**限制条款**，并且在数据 CSV 里逐列标注了"能不能引用"。

## 使用前请读

- 每个器件 README 末尾的 **"引用限制条款"** 是**原文保留**的。引用任何数值时请一并引用它，
  尤其 `rotate_adiabatic_BLT/` 的**器件级绝对插损不可引用**那一条。
