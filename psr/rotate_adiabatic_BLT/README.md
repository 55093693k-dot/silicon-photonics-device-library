# `PSR_ROTATE_ADIABATIC_BLT_v1` —— 绝热双台阶锥偏振旋转器

PSR 链**第二级**：把上一级送来的 **TM0 旋转为 TE0**，并从**窄波导（0.50 µm）**输出；
同时让 **TE0 输入原样留在宽波导（0.65 µm）**直通。

- 类型：偏振旋转器（TM0 → TE0），含锥形偏振分离（taper-type PSR）
- 平台：**SOI 220 nm + 90 nm 部分刻蚀**（侧壁角 10°），SiO₂ 包层
- 状态：🔄 **验证中 —— 机理 ✅ 已验证；器件级绝对插损 ❌ 未认证**
- 出处：**Flexcompute / Tidy3D 公开示例「BilevelPSR」在本平台上的适配版本**（出处链接见 §7）

> **术语（全文通用）**
> - 「**官方**」= 本器件所复刻的那个**公开示例**（几何参数全部取自该示例）。
> - 「**上臂 / 下臂**」= **宽输出臂（w_5 = 0.65 µm，y ≈ −0.10）/ 窄输出臂（w_6 = 0.50 µm，y ≈ −0.875）**。
>   TE0 输入留上臂直通；TM0 经 taper 转成 TE1 后由下臂输出。
> - 「**本平台**」= SOI 220 nm 顶层硅 + 90 nm 部分刻蚀 + SiO₂ 包层。
> - 「**成本单位**」= FlexCredit（Tidy3D 云端计费单位）。

## 1. 结构与工作原理

沿 +x 传播，两臂在 y 方向分离。结构分四段：

1. **双台阶锥（bi-level taper，x = 0…100 µm）**
   单条波导宽度 0.45 → 0.55 → 0.85 µm，底下带 90 nm 部分刻蚀平板（w_pes = 1.55 µm）。
2. **直段（L_s = 5 µm）**：宽度过渡衔接。
3. **绝热耦合器（adiabatic coupler，L_ac = 300 µm）**
   第二条波导在 x = 105 µm 处以 0.20 µm 宽度出现，并线性加宽至 0.50 µm；
   上臂由 0.85 µm 收窄到 0.65 µm；两臂间隙恒 **0.20 µm**。
   此段完成**模式演化**：输入的 TM0 在第一段被双台阶锥"塑造"成上臂的 TE1，
   再由绝热耦合器**绝热地**演化为下臂的 TE0。
4. **输出 S-bend（R = 300 µm，2θ = 12°，L_t = 30 µm）**：把两臂拉开到可分辨的间距后输出。

**原理要点**：转换依赖**绝热模式演化**（不是干涉 / 相位匹配），因此对波长与制造偏差不敏感，
但**要求整条拓扑完整** —— 缺任何一段都会使转换失效。

## 3. 性能

### 3.1 官方方法分段验证（3D，有效数据）

早前的全器件 EME 扫描受**端口模式基截断**影响、数值不可引用（见 §3.2），
因此改为**按官方方法分段验证**，两段互相印证：

| 段 | 方法 / 设置 | 结果 |
|---|---|---|
| **taper 段**（x −6…109 µm，TM0 注入） | 3D FDTD（Tidy3D 原生 ModeSource + ModeMonitor @ x = 105 µm，2 模式）；面内 12 steps/λ + z 向 20 nm 覆写；run_time 3.6 ps（≥2× 光程时间） | **TM0 → TE1 = 98.35%**（TM0→TE0 = 0.0000）；该段 IL ≈ 0.072 dB（**裁域 ⇒ 上界**） |
| **耦合器段**（x 100…410 µm，TE1 注入） | 3D EME（显式网格 69 单元；端口 x = 105 / x = 405；**6 模式**、`passive`、单频 1.55 µm） | **TE1 → 下臂 TE0 = 99.233%**（**已过 4→6 模式收敛：Δ = −0.29% < 2%**；4 模式值 99.525% 已被取代）；→ 上臂 5e-5；TE0 → 上臂 TE0 = 99.805%；TE0 → 下臂 TE0 = 2e-5 |

**端口模式识别（n_eff + 横向场重心，双证据）**

| 端口 | 模式 | n_eff | 场极性 / 横向重心 | 判定 |
|---|---|---|---|---|
| 入 x = 105 | 0 / 1 | **2.7027 / 2.2480** | Ey = 0.902 / 0.659 | **上波导 TE0 / TE1**（独立 FDTD 2.7059 / 2.252） |
| 出 x = 405 | 0 / 1 | 2.6057 / **2.4391** | 重心 −0.104 / **−0.866**（几何 −0.10 / −0.875） | **上臂 TE0 / 下臂 TE0** |

**结论**：机理由两段独立方法互证成立
（**TM0 →（taper）TE1 →（绝热耦合）下臂 TE0**）；**器件级绝对插损仍待补测**。
识别出的模式身份有**两条独立证据**（neff 与横向场重心位置），不是靠模式序号。

### 3.2 早前的全器件 EME 结果 —— 已判定为方法假象

| 指标 | 值 | 备注 |
|---|---|---|
| TM0 → 窄波导 TE0 | 92.4–96.7%（9 个频点） | **`unitary` / 4 端口模式 / 157 单元**；该输入列和 0.93–0.98 ≤ 1（物理自洽），但受**端口模式截断**主导 |
| TE0 通道去向（相对份额） | 留宽波导 TE0 99.74–99.95%；→ 窄波导 ≤ 0.0038%；→ TM ≤ 0.26% | 仅相对份额可辩 |
| 网格收敛性 | 单元数 60 → 157 时转换效率最小值 0.709 → 0.924 并趋于平坦 | 仅网格收敛，**模式基未收敛** |

**转折点**：同一条数值路线上，这台器件给出的结果**跨越两个数量级**，而且随**约束**与**端口模式数**变化：

| 运行 | 约束 | 端口模式数 | 结果 |
|---|---|---|---|
| 全器件 | `unitary` | 4 | 转换效率 **92.4–96.7%**（C 波段 9 频点） |
| 全器件 | `passive` | 2 / 4 / 6 | 透射从 **≈ 0.14%（IL ≈ 28.5 dB）** 到 **62%**，随模式数变化 |

⇒ 这些数**不可能都在描述同一个器件**；变的是**约束与端口模式基的大小**，不是器件。
⇒ 因此这些转换效率与 TE0 去向数值**一律标注为"不可引用"**。

### 3.3 自我反驳 —— 为什么"加模式数"这条路走不通

直觉是：EME 端口功率列和恒 ≈ 1，是因为端口模式数太少、辐射损耗没有出口；
所以把模式数从 2 提到 4 再提到 6，列和应该降到 < 1，辐射损耗就露出来了。

**实测结果否证了这个直觉**：

| 端口模式数 | 列和范围 | 转换率 |
|---|---|---|
| 4 | 0.99889 – 0.99999 | 99.525% |
| **6** | **0.99973 – 0.99999** | **99.233%（Δ = −0.29% < 2% ⇒ 已收敛）** |

⇒ 加模式数**没有**把列和压到 < 1。
**结论：在这个结构上，EME 无法给出辐射损耗** —— 器件级绝对插损须走
全器件 3D FDTD 或流片实测。

## 4. 引用限制条款（**引用本器件数值时必须一并引用**）

> **术语（本条款内不再重复）**：「上臂」= **宽输出臂**（w_5 = 0.65 µm，y ≈ −0.10）；
> 「下臂」= **窄输出臂**（w_6 = 0.50 µm，y ≈ −0.875）。TE0 输入留在上臂直通；
> TM0 经 taper 转成 TE1 后由**下臂**输出。**成本单位**：FlexCredit。

1. **可引用**：
   - 耦合器段 **TE1 → 下臂 TE0 = 99.233%**
     （6 模式 / `passive` / 单频 λ = 1.55 µm，**已过 4→6 模式收敛 Δ = −0.29%**）；
   - taper 段 **TM0 → TE1 = 98.35%**（3D FDTD，λ = 1.55 µm）。
2. **不可引用（未认证）**：**器件级绝对插损 / 回损**。
   依据（有证据）：EME 端口逐列和 ≈ 1（4 模式 0.99889–0.99999；6 模式 0.99973–0.99999）
   ⇒ **"增加端口模式数"不能暴露辐射损耗**（2026-09-12 实测**否证**）；
   该指标须走**全器件 3D FDTD**（估算 ≈30 FlexCredit）或**流片实测**。
   另：**输出段（S-bend + L_t，x 405…537.8 µm）未测** ⇒ 器件级插损未认证。
3. **仅单频**：上述数值只在 λ = 1.55 µm 验证；带宽曲线仍是**未收敛**数据
   ⇒ 只可作趋势，不可作指标。
4. **taper 段 IL 是上界**：域在 y 方向被裁窄 ⇒ 窗口外辐射被 PML 吸收，偏差只可能偏悲观。

## 5. 适用范围

| ✅ 适用 | ❌ 不适用 / 注意 |
|---|---|
| PSR 链的偏振旋转级（TM0 → TE0，窄臂输出） | 需要**绝对插损 / 回损**指标时（本设计数据不覆盖，需另行测量） |
| C 波段（1.50–1.58 µm）宽带宽工作 | 要求**单层全刻蚀**工艺的流程（本器件需要 **90 nm 部分刻蚀**） |
| SOI 220 nm 平台（含双层刻蚀能力） | 面积极度受限的场景（单器件 537.8 × ~12 µm） |
| 对波长 / 工艺偏差不敏感的设计（绝热机制） | 需要**多模 / 高阶模式**操作的场合（本设计仅处理 TE0 / TM0） |

## 6. 工艺与集成注意

- **必须支持 90 nm 部分刻蚀**（与 220 nm 全刻蚀构成双层）；侧壁角按 10° 建模。
- 两臂间隙 0.20 µm ⇒ 对光刻分辨率有要求（与典型的 SOI 深紫外工艺兼容）。
- 输出 S-bend 后两臂间距约 1.5–2 µm，便于接入后续器件。
- 器件总长 ≈ 538 µm：若面积紧张，可优先缩短绝热耦合器 L_ac
  （会牺牲转换效率与带宽，需重新优化）。

```powershell
# 依赖：pip install tidy3d==2.12；配置 API key
python sim\run_bilevel_psr.py --stage geometry      # 出整器件结构图（本地，免费）

python sim\run_bilevel_psr.py --stage eme --submit  # 真正提交（按估计成本计费）

# 官方方法分段复核
python sim\run_fdtd_short.py --pol tm               # taper 段 3D FDTD
python sim\run_eme_coupler.py --modes 4 --y 6       # 耦合器段 EME（先不带 --submit 看成本）
python sim\analyze_coupler_eme.py                   # 离线（0 成本）出认模与 T 矩阵
```
