# `PSR_SPLIT_TE_TM_DC_v1` —— TE/TM 分束器（等宽 DC + 长度选择）

PSR 链**第一级**：随机偏振从单臂输入，**TE0 留在输入臂（直通）**、**TM0 转移到相邻臂（交叉）**。

- 类型：偏振分束器（只分离，不含旋转）
- 平台：**SOI 220 nm 全刻蚀单层条波导**（不需要部分刻蚀工艺）
- 状态：🔄 **验证中 —— FDE 达标，3D 未 PASS。⚠️ 不得作为下游设计依据。**
- 出处：**本项目自研**（等宽定向耦合器 + 偏振相关耦合长度选择；无特定文献对应）

## 1. 结构与工作原理

沿 **+x** 传播；两臂沿 **z** 分开、以 z = 0 为中心对称；**高度沿 y**。

1. **耦合区**：两条**等宽** 450 nm 条波导，中心距 0.60 µm（间隙 **gap = 150 nm**），
   耦合长度 **L = 31.5 µm**。
2. **接入段**：两侧各 3 µm S-bend 渐近（横向偏移 **1.35 µm**）+ 2 µm 直段 stub
   （给源 / 监视器留白），避免平面端面直接散射，并让第二条波导从 x = 0 起平滑靠近。
3. **输出**：两臂在输出面处重新分开，供下游器件分别接入。

**原理**：等宽定向耦合器里，两支耦合超模（even / odd）的**耦合长度对偏振敏感**。
FDE 超模扫描给出 **L_c(TE) = 15.8 µm**、**L_c(TM) = 4.49 µm**（比 ≈ **3.52**）。
取 **L = 31.5 µm ≈ 2·L_c(TE) ≈ 7·L_c(TM)**（偶 / 奇整数倍关系）
⇒ **TE 走完整拍回原臂（直通）**、**TM 走到交叉臂（交叉）**。

设计意图就是"**用同一个 L 同时满足两种偏振的整数拍条件**" —— 这个思路本身是可复用的方法。

## 2. 关键参数

| 参数 | 值 | 备注 |
|---|---|---|
| 硅层高度 H | **220 nm** | y 方向 |
| 输入臂 w1 / 交叉臂 w2 | **450 / 450 nm** | **等宽**（分离靠偏振相关的 L_c，不靠宽度差） |
| 耦合间隙 gap | **150 nm** | 两臂中心距 0.60 µm |
| 耦合长度 L | **31.5 µm** | FDE 选出（= 2·L_c(TE) ≈ 7·L_c(TM)） |
| 接入 S-bend | 长 **3 µm**、横向偏移 **1.35 µm** | + 2 µm stub |
| 材料 | Si **n = 3.476** / SiO₂ **n = 1.444** | 全刻蚀条，无部分刻蚀 |
| 器件长度（含接入） | **≈ 35.5 µm** | 仿真域 z = ±3.0 µm、y = ±2.4 µm |
| 工艺 | 单层全刻蚀；**最小间隙 150 nm** | 与常规 SOI 深紫外工艺兼容 |

## 3. 性能

**数值方法**

1. **2D FDE 超模扫描**（本地）——孤立臂 neff（宽 400–600 nm）、配对超模 Δn 与失谐、
   全部宽度 / 间隙组合的最优 L 与偏振选择性排序 ⇒ **设计筛选**。
2. **3D FDTD 场积分法**（云端）——网格覆写 dl = (20, 10, 10) nm、四面 PML、run_time 3 ps、
   单频 λ = 1.55 µm、模式源 num_modes = 2 注入 wg1；输出面（x-normal）按臂窗口 **±0.45 µm**
   积分能流 **S_x = ½Re(E_y H_z\* − E_z H_y\*)**，并给出每臂的 **E_x / E_y 占比**判偏振。
   **不依赖端口模式序号**（规避端口法伪影）。
3. **参考直波导对照**（同一次 3D 链路）——确认模式序与链路可信度。

## 4. 这一版为什么没通过：三个"看起来像器件、其实是测量"的问题

这一段是本器件 README 最重要的部分。**把 92.65% 当成"略优化就能达标"是有风险的**：

1. **2D 与 3D 的 L_c 差了 8 倍。** FDE 给 L_c(TE) = 15.8 µm；由 3D 数据反推 **L_c(TE) ≈ 130 µm**
   （≈ 8×）。器件取 L = 31.5 µm ⇒ 在 3D 的实际耦合强度下**远未达到 2·L_c(TE)**。
   这与 FDE 的 99.99% 并不矛盾，属**未在 3D 内重定标**的必然结果。
   ⇒ **最终 L / gap 必须在 3D 内重新选取。**
2. **重定标扫描全部 FAIL，但不构成证据。** 那一轮扫描用的是**已被取代的端口法**，
   `TE_bar` 列在数据里空缺、`TM_cross ≈ 10⁻⁶`，判据（TE > 95% 且 TM > 95%）**无法评估**。
   也就是说：它是"测不出来"，不是"器件不行"。
3. **λ < 1534 nm 的"两臂能量 ≈ 0"** 与**参考直波导自身在该频段失效**
   （1503 nm 处 neff = 1.4891，已接近包层）**同时出现** ⇒ 主要归因于该频段的
   链路 / 模式求解失稳，而非器件本身（该归因有数据支撑，但**未完全排除器件因素**）。

### 自我反驳：为什么不把 92.65% 当成"差一点点"

- ① 92.65% 距 95% 只差 2.35 个百分点，**但缺收敛认证** ⇒ 这个差值可能来自网格 / 测量残差，
  **不能反推**"改一点就能过"。
- ② **参考直波导自身只有 99.71% / 92.05%** ⇒ 3D 链路本底损耗约 0.3–8%，
  92.65% 里可能含链路本底，**不能全部归给器件**。
- ③ 92.65% 是**相对份额**（P_wg1 /(P_wg1+P_wg2)），**不是绝对效率**；
  E_x 占比只说明偏振态，**不能证明没有辐射损耗**（T_total 未测）。

### 未认证项

TM 通道、绝对效率、网格收敛性（**未做收敛复跑**）⇒ **本器件不含任何"认证"级指标**。

| ✅ 适用 | ❌ 不适用 / 注意 |

| SOI 220 nm **单层全刻蚀**工艺（不需部分刻蚀） | 要求 TM 通道指标的场合（**TM 未测**） |
| λ = 1.55 µm 单频的 3D 验证数据 | 宽带指标引用（3D 只有单频；5 波长曲线是 **2D** 的） |

## 6. 工艺与集成注意

- **最小间隙 150 nm** ⇒ 需常规 SOI 深紫外（DUV）分辨能力；**间隙是性能最敏感的参数**。
- 单层全刻蚀，与 `../rotate_adiabatic_BLT/`（需 90 nm 部分刻蚀）**工艺不兼容**：
  两条路线若混用需评估额外的掩模 / 刻蚀步骤。
- 接入段 3 µm S-bend + 1.35 µm 偏移：下游器件需按此偏移对准，否则耦合会退化。
